# InvestCalc.eu

Static HTML/CSS/JavaScript investment calculator website prepared for Cloudflare deployment.

## SEO additions
- sitemap.xml
- robots.txt
- canonical URLs
- Open Graph and Twitter metadata
- Schema.org structured data
- basic 404 page

## Deployment
Upload all files to the GitHub repository connected to Cloudflare. After deployment, verify:
- https://investcalc.eu/sitemap.xml
- https://investcalc.eu/robots.txt

Then submit `sitemap.xml` in Google Search Console.
