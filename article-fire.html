Čo znamená FIRE

FIRE je skratka pre Financial Independence, Retire Early. Základná myšlienka je vytvoriť dostatočný majetok, aby výdavky neboli úplne závislé od aktívneho príjmu.

Výdavky určujú cieľ

Ak poznáš približné ročné výdavky, môžeš modelovo odhadnúť cieľové portfólio podľa zvoleného withdrawal rate. Nižší withdrawal rate znamená vyšší požadovaný kapitál.

Model nie je garancia

FIRE kalkulačka je zjednodušený model. Skutočný výsledok ovplyvní volatilita, poradie výnosov, inflácia, dane, zmeny výdavkov a ďalšie faktory.

Pracuj so scenármi

Skús zmeniť očakávaný výnos aj withdrawal rate. Namiesto jedného čísla sleduj viac scenárov a rozmer rozdielu medzi nimi.

Použiť kalkulačku

What FIRE means

FIRE stands for Financial Independence, Retire Early. The basic idea is to build enough assets so that spending is less dependent on active employment income.

Spending sets the target

Once you know approximate annual spending, you can model a target portfolio using a chosen withdrawal rate. A lower withdrawal rate implies a larger target portfolio.

The model is not a guarantee

The FIRE calculator is simplified. Actual outcomes are affected by volatility, sequence of returns, inflation, taxes, spending changes and many other factors.

Work with scenarios

Try changing both expected return and withdrawal rate. Instead of treating one number as certain, use multiple scenarios and focus on the range of possible outcomes.
