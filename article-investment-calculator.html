How to use an investment calculator

Ako správne nastaviť počiatočnú investíciu, mesačný vklad, výnosové scenáre a investičný horizont.

How to set an initial investment, monthly contribution, return scenarios and investment horizon.

Priestor pre reklamu

Začni počiatočnou sumou

Zadaj sumu, ktorú investuješ na začiatku. Ak plánuješ investovať jednorazovo väčšiu sumu, toto je základ modelu.

Pridaj mesačný vklad

Pravidelný vklad umožňuje modelovať situáciu, keď do portfólia pridávaš ďalší kapitál každý mesiac. Kalkulačka zároveň ukazuje samostatnú čiaru vlastných vkladov.

Použi tri scenáre

Namiesto jedného výnosu môžeš použiť tri predpoklady. To je užitočné, pretože budúci výnos nie je istý a výsledok je citlivý na dlhodobú mieru zhodnotenia.

Sleduj rozdiel medzi vkladmi a hodnotou

Prerušovaná línia vlastného kapitálu ukazuje, koľko peňazí si reálne vložil. Rozdiel medzi ňou a hodnotou portfólia predstavuje modelované zhodnotenie.

Použiť kalkulačku

Start with the initial amount

Enter the amount you invest at the beginning. If you plan a one-time larger investment, this is the starting point of the model.

Add a monthly contribution

A regular contribution models the case where you add more capital each month. The calculator also shows a separate line for your own contributions.

Use three scenarios

Instead of a single return assumption, you can use three scenarios. This is useful because future returns are uncertain and the outcome is sensitive to the long-term return assumption.

Watch the gap between contributions and value

The dashed contributed-capital line shows how much money you actually invested. The gap between that line and portfolio value represents modeled investment growth.
